## API Reference

| Prop      | Values                                                            | Default   |
| --------- | ----------------------------------------------------------------- | --------- |
| `variant` | `default`, `destructive`, `outline`, `secondary`, `ghost`, `link` | `default` |
| `size`    | `sm`, `default`, `lg`, `icon`                                     | `default` |

Every other prop is forwarded to Base UI's `Button`. `className` is narrowed to
a string: Base UI also accepts a function of the component's state, but the
variants here decide their classes without it.
